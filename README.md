# NoLegend · 不败扫描器

> **NO 不败（No-Lose）套利扫描器** —— 针对 Polymarket 多档互斥分区市场，自动识别「买入一组连续档位的 NO 后，无论结算落在哪里都不亏」的无风险机会，并输出可执行的等额买入方案。

---

## 项目简介

本项目扫描 Polymarket 上满足 **多档互斥分区结构** 的市场（例如「某城市某日最高气温落在哪一档」），对每个档位直接读取 **NO 订单簿的卖一价**，枚举所有连续子块组合，找出满足

```
Σ(NO 卖一价) ≤ (k − 1) 美元
```

的组合（k = 买入档位数）。只要该式成立，该组合即为**无条件不败**：

| 结算情形 | 回款 |
|---|---|
| 结算落在所买 k 档之内 | 恰好 1 档 NO=0，其余 k−1 档 NO=1 → 回款 **k−1 美元/份** |
| 结算落在所买 k 档之外 | k 档全部 NO=1 → 回款 **k 美元/份** |

最坏情形（块内结算）回款 k−1 ≥ 投入 Σno，因此**不依赖结算结果，真不败**。

---

## 核心特性

- 🎯 **只做 NO 侧**：不碰 YES，不从 YES 推导 NO 价格，只用订单簿真实卖一价（`asks[-1]`，Polymarket CLOB 返回降序数组，最低卖价在末尾）
- 🧩 **互斥分区校验**：仅处理 `negRisk=True` 的市场（恰好一档结算 $1）。自动剔除累计阈值盘（如「≥3000 病例」）、多结果盘（如「哪些国家发生」）——这类市场可同时结算多个 YES，NO 不败模型不成立
- 🔍 **全量扫描**：分页拉取 Gamma API 全量事件，动态市场不遗漏；二元盘（1 档）自动跳过
- 💰 **手续费核算**：读取 Gamma `feeSchedule.rate`（Taker 费率），按官方公式 `fee = C × feeRate × p × (1-p)` 计算，输出**手续费后**的块内/块外收益与收益率
- 📊 **真子组合识别**：区分全仓（k=n）与真子组合（k<n），全仓无块外分支，如实标注「无块外选项」
- 📢 **多端输出**：控制台渲染、飞书机器人卡片通知、本地日志（命中历史 + 运行记录）

## 快速开始

### 环境要求

- Python 3.8+
- 依赖：`requests`

```bash
pip install requests
```

### 运行

```bash
python polymarket_no_arbitrage_scanner.py
```

可选参数：

```bash
python polymarket_no_arbitrage_scanner.py --verbose   # 额外输出各事件最接近门槛的组合
```

### 配置（脚本头部常量）

| 常量 | 默认值 | 说明 |
|---|---|---|
| `N_PER_BUCKET` | 10 | 每档固定买入份数 |
| `MAX_RANGE` | 11 | 子块最大跨度（档位数） |
| `MAX_RANGE_BY_TAG` | 字典 | 按 tag 单独配置子块上限（选举 23、宏观 21 等） |
| `CATEGORIES` | 字典 | 扫描的 tag 列表（天气 / CPI / GDP / 美联储 / 利率 / 失业率 / 通胀 / 宏观指标 / 选举 / 地震） |
| `LARK_WEBHOOK` | 内置地址 | 飞书机器人 webhook（可用环境变量 `FEISHU_WEBHOOK` 覆盖） |
| `POLY_PROXY` | `http://127.0.0.1:7897` | Polymarket API 代理（可用环境变量 `POLY_PROXY` 覆盖） |

## 数据源（硬性约束）

- **发现市场**：Polymarket 官方 Gamma API（`https://gamma-api.polymarket.com`）
- **取价**：CLOB API（`https://clob.polymarket.com`）订单簿，NO 档位 `asks` 数组**最后一个**元素为最低卖一价
- **费率**：Gamma 市场字段 `feeSchedule.rate`（字段缺失视为零费率）
- 不使用 `outcomePrices` 概率作为价格依据（概率反应慢于订单簿）

## 策略原理与风险提示

### 为什么会出现不败机会

多档分区市场中，各档 NO 卖一价之和通常接近 k−1（市场有效定价）。当市场滞后、错价或流动性不足导致「局部档位 NO 卖一价之和 ≤ k−1」时，出现无风险窗口。

### 重要风险提示

1. **手续费会侵蚀保底收益**：`Σno` 恰好贴住门槛的组合，扣手续费后块内可能为负。请以「手续费后收益」为准评估。
2. **真子组合的块外收益是小概率事件**：未买档位的结算概率通常极低（市场隐含 <2%），块外彩票价值有限，期望收益需自行结合概率模型判断。
3. **成交价假设**：卖一价仅保证第一份以该价成交，实际批量买入可能滑点。
4. **务必核对互斥性**：本项目以 `negRisk=True` 过滤非互斥市场；实盘前请再次确认市场结算规则（恰好一档结算 $1）。
